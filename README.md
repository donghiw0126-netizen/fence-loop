# 울타리 잇기 (Fence Loop)

언제든 새 문제를 풀 수 있는 슬리더링크 퍼즐 웹게임입니다. (HTML/CSS/JS, 서버 없음)

## 규칙
- 이웃한 점끼리 선을 이어 끊기지 않는 고리 하나를 만듭니다.
- 칸 안의 숫자는 그 칸의 네 변 중 선이 지나가는 변의 개수입니다.
- 모든 문제는 정답이 하나뿐인지 컴퓨터가 확인한 뒤에 나옵니다.

## 난이도
| 난이도 | 판 | 남기는 숫자 |
|---|---|---|
| 쉬움 | 5×5 | 60% 이상 |
| 보통 | 7×7 | 45% 이상 |
| 어려움 | 10×10 | 지울 수 있는 만큼 (보통 35~40%) |

## 파일
- `logic.js` — 문제 만들기·풀이기·판정·힌트 고르기 (화면과 무관, 테스트 대상)
- `game.js` — 화면 동작 (입력, 되돌리기, 힌트, 저장, 타이머, 최고 기록)
- `index.html`, `styles.css` — 화면 구조와 디자인
- `sw.js`, `manifest.webmanifest`, `icon*.png`, `icon.svg` — 앱 설치·오프라인 실행(PWA). 서비스 워커는 배포된 사이트에서만 켜짐
- `tests/logic.test.js` — 난이도별 30문제가 정답 하나인지 등 점검
- `tests/pwa.test.js` — PWA 파일 목록·아이콘·배포 설정이 서로 맞는지 점검

새 파일을 만들면 `.github/workflows/deploy.yml` 의 복사 목록(과 필요하면 `sw.js` 저장 목록)에도 넣어야 배포됩니다.

## 실행
- 그냥 `index.html` 을 더블클릭해도 됩니다.
- 또는 `npm start` 후 http://localhost:8002
- 테스트: `npm test`
